# Showcase Projects

This repository contains the code behind the showcase projects Luxonis builds for demos, blog posts and videos that show what OAK devices can do in real builds.

> [!WARNING]
> The code here is **unmaintained** and shared **for reference only**. Each project was written for one demo, on one hardware setup, at a single point in time. It may depend on specific DepthAI, Luxonis OS or OAK App base image versions, hard-coded device IPs, or custom hardware, and it is not tested against newer releases.

**Looking for examples to build on?** See [**oak-examples**](https://github.com/luxonis/oak-examples). It has small, standalone, minimal-code examples of individual OAK features (camera control, depth, neural networks, encoding and more), and it is the place to learn the core features.
